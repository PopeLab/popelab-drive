PopeLab Drive

A personal Google Drive integration operated by Joshua Pope using rclone on owner-controlled computers.

Purpose and access

The integration makes the owner's Google Drive files available through a local desktop folder. Depending on the permissions granted, it can list, download, upload, rename, and delete files and folders.

Google account authorization takes place through Google's consent screen during local rclone setup. This website provides information about the integration and its data practices.

Personal use

This integration is intended for the owner's personal account and devices.
